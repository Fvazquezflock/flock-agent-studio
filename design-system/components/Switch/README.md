Interruptor para activar o desactivar algo al instante.

## Cuándo usarlo
- Preferencias que se aplican sin botón Guardar (notificaciones, tema). Dentro de formularios con Guardar, usá `Checkbox`.

## Qué provee el consumidor
- `label`, `checked` / `defaultChecked` / `onChange(checked)`, `disabled`, `size` (`sm` | `md`).

## Reglas
- El label nombra lo que se activa, no el estado: "Notificaciones por mail".
