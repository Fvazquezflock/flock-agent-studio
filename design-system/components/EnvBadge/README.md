Indica en qué ambiente estás: DEV, TEST, UAT o PROD.

## Cuándo usarlo
- Siempre visible en el `Header` de ambientes no productivos. `strip` agrega una franja de 4px arriba de todo.

## Qué provee el consumidor
- `env` (`dev` · `test` · `uat` · `prod`), `strip`.

## Reglas
- Colores fijos de marca: DEV índigo, TEST naranja, UAT orquídea, PROD magenta. No los uses para otra cosa.
