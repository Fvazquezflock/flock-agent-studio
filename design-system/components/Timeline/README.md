Historial de actividad o auditoría de un registro.

## Cuándo usarlo
- Pestaña "Historial" de un detalle, cambios de estado, trazabilidad de aprobaciones.

## Qué provee el consumidor
- `items` `{ title (puede incluir <b>), meta ("Persona · fecha hora"), tone (success · warning · danger · info · brand), icon, content }`.

## Reglas
- Más reciente arriba. Fechas dd/mm/aaaa hh:mm. El tono acompaña al ícono, nunca solo.
