Pantallas de error: 404, 403 (sin permisos), 500 y mantenimiento (503).

## Cuándo usarlo
- Rutas inexistentes, accesos denegados, fallas del servidor y ventanas de mantenimiento. `brand` para pantallas fuera del `AppShell`.

## Qué provee el consumidor
- `code` (404 · 403 · 500 · 503), `title` y `children` para reemplazar los textos por defecto, `actions`, `requestId` (para soporte), `brand`, `logoSrc`.

## Reglas
- Nunca culpes a la persona. Siempre una salida: "Ir al inicio".
