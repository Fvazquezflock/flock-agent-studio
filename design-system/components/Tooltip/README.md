Ayuda breve al pasar el mouse o enfocar; etiqueta de los botones de solo ícono.

## Cuándo usarlo
- Para nombrar un `IconButton` o aclarar un dato abreviado. Si la información es necesaria para completar una tarea, escribila en pantalla.

## Qué provee el consumidor
- `content`, `children` (el disparador), `placement` (`top` · `bottom` · `right`), `wrap` (texto de varias líneas), `open` (forzar).

## Reglas
- Una línea, sin acciones ni links adentro (para eso, `Popover`). Invertido: fondo `ink`, texto `surface`.
