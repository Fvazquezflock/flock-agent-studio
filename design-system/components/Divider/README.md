Línea que separa bloques; puede llevar un texto centrado.

## Cuándo usarlo
- Entre grupos dentro de una card o formulario. Entre secciones de página alcanza con espacio (`space-40`).

## Qué provee el consumidor
- `label`, `vertical`, `strong` (`border-strong`).

## Reglas
- Usalo con moderación: el espacio separa mejor que las líneas.
