Secciones colapsables para contenido secundario o largo.

## Cuándo usarlo
- Preguntas frecuentes, detalles opcionales, grupos de configuración. No escondas información crítica.

## Qué provee el consumidor
- `items` `{ title, meta, icon, content, defaultOpen }`, `multiple` (varias abiertas), `variant` (`plain` | `card`), `defaultOpen` (índices).

## Reglas
- Títulos que anticipan el contenido. Chevron a la derecha que gira al abrir.
