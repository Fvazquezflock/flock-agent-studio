Buscador pill con ícono, limpiar y atajo de teclado opcional.

## Cuándo usarlo
- Búsqueda en tablas, listas y en el header. Para elegir un valor de una lista usá `Combobox`.

## Qué provee el consumidor
- `value` / `defaultValue` / `onChange`, `onSearch(value)` al apretar Enter, `placeholder` (qué se busca), `shortcut` ("Ctrl+K"), `size`.

## Reglas
- El placeholder dice qué campos busca: "Buscar por partner o CUIT".
