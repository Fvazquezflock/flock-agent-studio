Etiqueta para categorías, tecnologías o palabras clave; puede ser seleccionable o removible.

## Cuándo usarlo
- Tecnologías de un proyecto (como los casos de éxito del sitio), categorías, filtros rápidos tipo chip.
- Para estados de un registro usá `StatusBadge`.

## Qué provee el consumidor
- `children`, `onRemove`, `selected` + `onClick` (seleccionable), `variant` (`brand`: violeta noche con borde naranja), `size`, `swatch` (color), `icon`.

## Reglas
- Texto corto (1–3 palabras). No mezcles tags seleccionables y removibles en la misma fila.
