Alterna entre pocas vistas o períodos mutuamente excluyentes.

## Cuándo usarlo
- 2 a 5 opciones cortas que cambian la vista al instante (Día / Semana / Mes, Tabla / Tarjetas).

## Qué provee el consumidor
- `options`: strings o `{ value, label, icon }`; `value` / `defaultValue` / `onChange`; `size` (`sm` | `md`); `block`; `label` (accesible).

## Reglas
- No lo uses dentro de formularios para datos que se guardan: para eso está `RadioGroup`.
