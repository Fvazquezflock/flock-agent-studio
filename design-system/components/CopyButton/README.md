Copiar al portapapeles un ID, CUIT o link, con confirmación.

## Cuándo usarlo
- Datos que la gente copia para pegar en otro sistema: códigos, CUIT, CBU de prueba, URLs.

## Qué provee el consumidor
- `value`, `label` (por defecto "Copiar"), `showValue` (muestra el valor en mono junto al botón), `copiedLabel`.

## Reglas
- Confirmá con el ícono de check y el tooltip "Copiado" durante ~1,5 s.
