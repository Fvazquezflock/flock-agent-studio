Texto de varias líneas para observaciones y descripciones.

## Cuándo usarlo
- Texto libre de más de una oración. Para comentarios con menciones usá `Comments`.

## Qué provee el consumidor
- `value` / `defaultValue` / `onChange`, `rows` (por defecto 3), `maxLength` (muestra contador), `invalid`, `disabled`, `placeholder`.

## Reglas
- Se redimensiona solo en vertical. Con límite, mostralo siempre.
