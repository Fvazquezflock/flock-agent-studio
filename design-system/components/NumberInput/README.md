Números e importes con formato argentino: 1.234,56 y $ 1.234,56.

## Cuándo usarlo
- Montos, tarifas, porcentajes y cantidades. Acepta coma o punto al tipear y formatea al salir del campo.

## Qué provee el consumidor
- `value` / `defaultValue` (número) / `onChange(number)`, `currency` (prefijo $), `prefix`, `suffix`, `decimals`, `min`, `max`, `size`, `invalid`, `disabled`.

## Reglas
- Alineado a la derecha con cifras tabulares. Indicá la moneda o la unidad siempre.
