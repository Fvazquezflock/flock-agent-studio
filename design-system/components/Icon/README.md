Set de íconos de línea (Lucide, licencia ISC) con trazo de 1.75px y puntas redondeadas.

## Cuándo usarlo
- En botones, navegación, estados y campos. Todo componente que acepta `icon` recibe uno de estos nombres.

## Qué provee el consumidor
- `name` (ver la grilla), `size` (16 en controles chicos, 18–20 por defecto), `strokeWidth`, `label` (solo si el ícono transmite información por sí solo; si no, es decorativo).

## Reglas
- Color heredado (`currentColor`): `ink-muted` por defecto, `primary-text` activo, color de estado solo junto a texto.
- No mezclar con otros sets ni con emojis. Para sumar un ícono, agregalo desde Lucide al bundle.
