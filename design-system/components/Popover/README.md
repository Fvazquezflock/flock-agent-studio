Panel flotante con contenido interactivo, anclado a un disparador.

## Cuándo usarlo
- Información contextual con acciones (vista previa de una persona, explicación con link, mini formulario de una línea).

## Qué provee el consumidor
- `trigger`, `title`, `children`, `footer`, `open` / `defaultOpen` / `onOpenChange`, `placement`, `width`.

## Reglas
- Contenido corto. Si necesita scroll o más de 3 campos, usá `Modal` o `Drawer`.
