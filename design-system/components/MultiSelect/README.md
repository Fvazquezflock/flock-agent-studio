Selección de varias opciones, mostradas como chips removibles.

## Cuándo usarlo
- Asignar varias etiquetas, partners o personas a un registro. Para filtrar una tabla preferí `FilterDropdown`.

## Qué provee el consumidor
- `options`, `value` / `defaultValue` (array) / `onChange`, `placeholder`, `maxChips` (resto como "+N"), `size`, `invalid`, `disabled`.

## Reglas
- Backspace con el campo vacío quita el último chip.
