Tecla o atajo de teclado.

## Cuándo usarlo
- En menús, ayudas y `CommandPalette` para enseñar atajos.

## Qué provee el consumidor
- `keys` ("Ctrl+K" o un array) o `children` para una sola tecla.

## Reglas
- Nombres en español donde aplique ("Mayús", "Supr"); "Ctrl" en Windows, "⌘" solo si el producto es exclusivo de Mac.
