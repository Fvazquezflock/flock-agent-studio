Enlace de navegación dentro de texto, celdas y ayudas.

## Cuándo usarlo
- Para ir a otra pantalla o recurso. Si dispara una acción (guardar, borrar), es un `Button`.

## Qué provee el consumidor
- `href`, `children`, `variant` (`default` en `primary-text` · `quiet` en `ink` · `muted`), `external` (abre en pestaña nueva con ícono).

## Reglas
- Siempre subrayado salvo `muted` en navegación secundaria.
- Texto que describe el destino: "Ver contrato", nunca "click acá".
