Tarjeta de una persona: rol, equipo, contacto y acciones rápidas.

## Cuándo usarlo
- Directorio del equipo, responsables de un partner, vista previa al pasar sobre un avatar (dentro de un `Popover`).

## Qué provee el consumidor
- `name`, `role`, `email`, `phone`, `location`, `team` (tag de marca), `tags`, `avatar`, `status`, `actions` (o `false` para ocultarlas).

## Reglas
- Datos de contacto laborales solamente.
