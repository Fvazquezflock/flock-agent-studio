Selector con búsqueda para listas largas (partners, clientes, personas).

## Cuándo usarlo
- Más de ~10 opciones, o cuando la persona sabe qué busca. Resalta la coincidencia y acepta teclado.

## Qué provee el consumidor
- `options` (como `Select`), `value` / `defaultValue` / `onChange`, `placeholder`, `icon`, `emptyText`, `size`, `invalid`, `disabled`.

## Reglas
- Si no hay resultados, decilo: "Sin resultados para 'xyz'". Para varias opciones usá `MultiSelect`.
