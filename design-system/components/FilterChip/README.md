Un filtro activo, removible.

## Cuándo usarlo
- Para mostrar qué filtros están aplicados (lo hace `FilterBar` automáticamente) o en búsquedas avanzadas.

## Qué provee el consumidor
- `label` (la dimensión), `value` (el valor legible), `onRemove`.

## Reglas
- Formato "Dimensión: valor". Un chip por valor.
