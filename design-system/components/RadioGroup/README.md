Elegir exactamente una opción entre pocas, todas visibles.

## Cuándo usarlo
- 2 a 5 opciones que conviene comparar. `cards` para opciones con descripción más larga.

## Qué provee el consumidor
- `legend`, `options` (strings o `{ value, label, description, disabled }`), `value` / `defaultValue` / `onChange`, `row`, `cards`, `name`.

## Reglas
- Siempre una opción preseleccionada si hay un valor por defecto razonable.
