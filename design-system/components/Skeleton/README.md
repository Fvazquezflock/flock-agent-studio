Marcador de posición mientras carga el contenido, con la forma del contenido final.

## Cuándo usarlo
- Primera carga de tablas, cards y detalles. `DataTable loading` ya lo usa.

## Qué provee el consumidor
- `width`, `height`, `circle`, `lines` (párrafo), `radius`.

## Reglas
- Respetá la estructura real (mismas columnas, mismos tamaños). Respeta `prefers-reduced-motion`.
