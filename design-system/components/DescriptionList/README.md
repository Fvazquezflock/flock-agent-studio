Detalle clave–valor de un registro.

## Cuándo usarlo
- Fichas de detalle (partner, contrato, período), dentro de una `Card` o un `Drawer`.

## Qué provee el consumidor
- `items` `{ label, value, span, copy }` (`copy`: un `CopyButton`), `columns` (por defecto 2), `variant` (`grid` | `rows`).

## Reglas
- Valor vacío se muestra como "—". Fechas dd/mm/aaaa; montos con $ y formato AR.
